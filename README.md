# Internet de las Cosas en Rusia

Presentación web interactiva para la exposición de la Unidad 1.

## Ver la presentación

[Abrir la presentación publicada](https://marcoantoniocardenassanchez.github.io/InternetDelasCosas/)

## Uso local

Abre `index.html` en cualquier navegador. Las flechas cambian de diapositiva y la tecla `F` activa la pantalla completa.

Los guiones para los tres participantes están en `LIBRETOS_3_PARTICIPANTES.txt`.

## Publicación

El flujo de GitHub Actions incluido publica automáticamente la raíz del repositorio en GitHub Pages cuando se envían cambios a la rama `main`.
